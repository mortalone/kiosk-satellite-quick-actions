# Quick Actions & Clock 0.2.16

- Direct text entry (`string`) for all six display and action entities (`item1Entity` to `item6Action`).
- Eliminates Kiosk Satellite's restrictive entity picker filter which omitted generic `sensor.*` domains.
- Freely paste or type any Home Assistant entity ID, such as vehicle battery levels (`sensor.citroen_batteri`, `sensor.lsjwx4098tn028453_soc`), temperature sensors, persons, scripts or switches.
- Retains up to six entity slots, Danish Home Assistant layout controls, and compact 19 manifest settings.
